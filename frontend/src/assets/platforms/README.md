# Platform brand assets

`seedance.svg` uses the ByteDance Seed mark shown by the official Seedance
website (`https://seed.bytedance.com/en/seedance2_0`). Its favicon is published at
`https://lf3-static.bytednsdoc.com/obj/eden-cn/lapzild-tss/ljhwZthlaukjlkulzlp/favicon_1/favicon.ico`.
The matching vector paths come from the existing `@lobehub/icons` ByteDance
color asset. The SVG is bundled locally for both platform and model icons;
rendering never contacts either upstream source.
